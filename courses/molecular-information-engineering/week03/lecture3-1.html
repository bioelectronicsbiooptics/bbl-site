디지털 데이터란 — 파일은 바이트 열

bit → byte → 16진수 → 파일

단위크기예
bit0 또는 1트랜지스터 1개 · 염기 반 개(2 bits/nt 기준)

  • 컴퓨터의 모든 것 = 0/1 · 8개 묶음 = 1 byte
  • 16진수(hex) = 4 bit씩 묶어 0~F로 표기 · 1 byte = 두 자리
  • 파일 확장자(.txt .jpg .mp3)는 "해석 규칙" 표시일 뿐 · 내용은 전부 바이트 열

  • 1 KB = 1,000 B(SI) vs 1 KiB = 1,024 B — 논문 용량 비교 시 주의

ASCII 문법 — 글자를 숫자로

American Standard Code for Information Interchange (1963) · 7 bit · 128 코드

  • 0~31 제어문자(줄바꿈 10, 탭 9) · 32 공백 · 127 DEL
  • 48~57 = 숫자 0~9 (0x30~0x39)
  • 65~90 = A~Z (0x41~) · 97~122 = a~z (0x61~)
    • 대·소문자 차이 = 32 = 0x20 = bit 5 하나
  • 8번째 bit는 0 → 확장 ASCII(128~255)는 지역마다 다름
  • 한글은? → Unicode · UTF-8: 1~4 byte 가변, 한글 1자 = 3 byte
    • "송" = U+C1A1 → EC 86 A1
ord('A') → 65      chr(65) → 'A'      format(65, '08b') → '01000001'      '송'.encode('utf-8') → b'\xec\x86\xa1'   (Python)
double('A') → 65   char(65) → 'A'     dec2bin(65, 8) → '01000001'         unicode2native('송','UTF-8') → [236 134 161]   (MATLAB)

음성 · 노래 — 파형을 숫자로

표본화(sampling) · 양자화(quantization) · 압축

  • 표본화: 초당 몇 번 재는가 — Nyquist: 최고 주파수의 2배 이상
    • 사람 가청 20 kHz → CD 44.1 kHz
  • 양자화: 한 번 잴 때 몇 bit — CD 16 bit = 65,536 단계
  • CD 음질 = 44,100 × 16 × 2채널 = 1,411 kbit/s
    • 3분 노래(WAV) = 1,411,200 × 180 ÷ 8 ≈ 31.7 MB
  • MP3 128 kbit/s ≈ 2.9 MB — 약 1/11 · 귀에 안 들리는 성분 제거(심리음향)
  • 저장 관점: 압축 = 중복 제거 → 압축 파일은 비트 하나가 더 소중해짐

이미지 — 픽셀을 숫자로

pixel · RGB · 해상도 · 원시 크기

압축 파일과 오류 전파 — DNA 저장에 ECC가 필수인 이유

  • 29,531 byte 중 1 byte만 바뀌어도 그 지점부터 화면이 깨짐
  • 가변길이(Huffman) 부호는 "경계"가 데이터에 의존 → 한 비트가 어긋나면 경계가 밀림 = 동기화 상실

DNA 서열의 제약 ① — 호모폴리머 · GC 함량 · Tm

"쓸 수 있는 서열"과 "쓸 수 없는 서열"

[퀴즈 예고]

"AAAA"가 왜 "ACAC"보다 위험한가? 시퀀서가 A를 4개 읽었는지 5개 읽었는지 어떻게 아는가?

  • 호모폴리머(homopolymer) — 같은 염기 연속
    • 합성 시 미끄러짐(slippage) · 나노포어·pyrosequencing은 길이를 세지 못함 → 보통 ≤ 3~4
  • GC 함량 — 전체 중 G+C 비율
    • 40~60%(엄격히 45~55%) · 낮으면 Tm↓·프라이밍 불안정, 높으면 이차구조·합성 난도·PCR 편향
  • Tm(녹는점) — 이중가닥의 절반이 풀리는 온도
    • Wallace: Tm ≈ 2(A+T) + 4(G+C) °C (≤ 20 nt) · 정확히는 최근접이웃(nearest-neighbor) 열역학
    • 한 pool 안의 올리고들은 Tm이 비슷해야 같은 PCR 조건에서 균일 증폭

나노포어(Delahaye 2021): 호모폴리머 ≥ 8이면 정확도 25% 이하 · 전체 오류의 47%가 호모폴리머 구간 · Twist 합성 절대 한계 14 bp · Erlich 2017 규칙: ≤ 3, GC 45~55%

Mapping Bits to Bases

"DNA"를 DNA로 쓰기 — 세 가지 매핑

ASCII 24 bit → 12 nt / 24 nt / 15 nt

  • ① 2 bits/nt 직접 매핑 — 00 A · 01 C · 10 G · 11 T
    • 가장 조밀(2.0 bits/nt) · 그러나 00000000 → AAAA 호모폴리머 그대로 노출
  • ② 1 bit/nt (Church 2012) — 0 → A 또는 C, 1 → G 또는 T
    • 같은 비트가 이어져도 다른 염기를 고를 수 있어 호모폴리머 회피 · 밀도 1.0
  • ③ 3진 회전 (Goldman 2013) — 다음 장
    • 밀도 1.58 · 호모폴리머 원천 차단

길이 2 bits/nt 대비 26% 증가 · 대신 검사 없이도 제약 보장

  • 2 단계: 직전 염기를 제외한 3개 중 trit로 선택

  • 밀도 log₂3 = 1.585 bits/nt · 실제 Goldman 1.58

오늘의 정리

제3강(3주차-1) 핵심 여섯 문장

  1. 파일은 확장자와 무관하게 바이트 열 · hexdump로 확인 가능
  2. ASCII 7 bit · UTF-8 한글 3 byte · 소리는 표본화+양자화 · 그림은 픽셀×RGB · 영상은 그림×시간
  3. JPEG의 손실은 양자화에서만 · Huffman 가변길이 때문에 비트 하나 오류가 전파됨
  4. DNA는 호모폴리머·GC·Tm·이차구조·반복·금지서열 제약 아래서만 쓸 수 있음
  5. 1 bit/nt(1.0) · 3진 회전(1.58) · 2 bits/nt(2.0) — 규칙이 강할수록 밀도는 낮아짐
  6. 인코딩 규칙을 아는 사람만 읽을 수 있다 — 인코딩 명세 = 사실상 암호키 (다보스 사례)
