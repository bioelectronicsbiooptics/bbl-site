8 bit 이론 · 인코딩 기초

One Byte, Four Bases

  • 1 글자 = 1 byte = 8 bit = 4 nt
  • 매핑표 하나가 인코더의 전부
  • 되돌리려면 역매핑표

8 bit → 4 nt — 인코딩 기초

  • 영문 1글자 = 8 bit = 2 bit × 4 = 4 nt · 이름 n글자 = 4n nt
  • 한글 1글자 = UTF-8 3 byte = 24 bit = 12 nt
  • 인코더 = ① 글자→비트 ② 2 bit씩 자르기 ③ 표 찾기 · 디코더 = 역순 + 역표(A→00 …)
  • 표를 바꾸면 규칙이 바뀜(00→T로 하면 전혀 다른 서열) · 표를 모르면 읽을 수 없음 (지난주 다보스 사례)
  • 제약 검사는 인코딩 "뒤"에 — GC%와 최대 연속 길이를 세어 판정

Python — 이름 인코딩 ①②③ (5분)

셀 3개 · 각 셀 실행 후 출력 확인

week3_dna.ipynbGoogle Colab ↗
# 셀 1: 이름 → 비트
name = "SONG"                      # ← 자기 이름
bits = "".join(format(ord(c), "08b") for c in name)
print(bits, len(bits))

# 셀 2: 비트 → DNA (2 bits/nt)
m = {"00": "A", "01": "C", "10": "G", "11": "T"}
dna = "".join(m[bits[i:i+2]] for i in range(0, len(bits), 2))
print(dna, len(dna))

# 셀 3: GC% · 최대 호모폴리머
gc = (dna.count("G") + dna.count("C")) / len(dna) * 100
run, maxrun = 1, 1
for i in range(1, len(dna)):
    run = run + 1 if dna[i] == dna[i-1] else 1
    maxrun = max(maxrun, run)
print(f"GC={gc:.1f}%  maxrun={maxrun}")
기대 출력 ("SONG")
01010011010011110100111001000111 32
CCATCATTCATGCACT 16
GC=43.8%  maxrun=2
  • 셀 2: range(0, 32, 2) → 0,2,4,… · bits[i:i+2]가 2 bit 조각 · m[…]이 표 찾기
  • 셀 3: 앞 글자와 같으면 run+1, 다르면 1로 리셋 · 최댓값 기억
  • 판정: GC 40~60%? maxrun ≤ 3? → 둘 다 통과하면 "합성 가능"
  • 지난주 손 계산과 비교 — 다르면 어느 쪽이 틀렸는지 찾기
흔한 오류

같은 다섯 단계를 행렬 표기로

week3_dna.mMATLAB Online ↗
%% 1: 이름 → 비트
name = 'SONG';                       % ← 자기 이름
bits = reshape(dec2bin(double(name), 8)', 1, []);
disp(bits); disp(length(bits))

%% 2: 비트 → DNA (2 bits/nt)
map = 'ACGT';                        % 00→A 01→C 10→G 11→T
pairs = reshape(bits, 2, [])';       % 16×2 문자 행렬
idx = bin2dec(pairs);                % 0..3
dna = map(idx + 1)                   % 1부터 세므로 +1

%% 3: GC% · 최대 호모폴리머
gc = sum(dna == 'G' | dna == 'C') / length(dna) * 100;
runs = diff([0, find(diff(double(dna)) ~= 0), length(dna)]);
maxrun = max(runs);
fprintf('GC=%.1f%%  maxrun=%d\n', gc, maxrun)
기대 출력 ("SONG")
01010011010011110100111001000111
    32
dna = 'CCATCATTCATGCACT'
GC=43.8%  maxrun=2
  • reshape(bits, 2, [])' → 2 bit씩 한 행 · bin2dec가 행마다 숫자로
  • map(idx+1) — 딕셔너리 대신 "문자열 인덱싱" · MATLAB다운 매핑표
  • diff(double(dna)) ≠ 0 인 곳 = 염기가 바뀌는 곳 → 그 간격이 연속 길이

dna1 = ""
for i, b in enumerate(bits):
    if b == "0":
        dna1 += "A" if i % 2 == 0 else "C"
    else:
        dna1 += "G" if i % 2 == 0 else "T"

MATLAB — 같은 규칙MATLAB Online ↗
dna1 = blanks(length(bits));
for i = 1:length(bits)
    if bits(i) == '0'
        if mod(i,2)==1, dna1(i)='A'; else, dna1(i)='C'; end
    else
        if mod(i,2)==1, dna1(i)='G'; else, dna1(i)='T'; end
    end

  • GC%는 50% 근처로 수렴(0/1이 반반이면) · 밀도 1.0 bits/nt가 대가

name = "송영준"
