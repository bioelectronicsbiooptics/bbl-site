Extension 신장

  • 효소와 길이에 따른 반응 시간

PCR 증폭의 수학

  • 초기 사본 수 N0
  • 사이클 효율 E: 0≤E≤1의 단순 모형
  • c회 후 N=N0(1+E)^c
  • E=1의 이상 조건에서 N=N02^c

N(c) = N₀(1 + E)^c

확인·실습 문제

N₀=100, E=1, c=10인 이상 모형의 산물 수 계산

https://doi.org/10.1038/nbt.4079

  • 파일 A의 두 주소에 맞는 프라이머
  • A의 분자들이 우선 증폭
  • 파일 B·C의 비표적 분자는 반응 후에도 존재 가능

무작위 분주와 Poisson 모형

  • 평균 사본 수 λ인 분주를 가정
  • 특정 서열이 하나도 없을 확률: exp(−λ)
  • λ=1: 약 36.8%, λ=10: 약 0.0045%
  • 균일·독립 분주를 가정한 예제

P(N=0) = exp(−λ)

Boolean search 분자 검색

  • 서로 다른 태그에 서로 다른 탐침 사용
  • AND: 여러 조건을 동시에 만족하는 캡슐
  • OR: 어느 한 조건을 만족하는 캡슐
  • NOT: 특정 태그를 제외하는 선택
