위쪽 계층 — SRAM과 DRAM

전기 공급이 필요한 기억(휘발성)

SRAM

6개 트랜지스터 래치 = 1 bit

  • refresh 불필요 → 가장 빠름 (1–20 ns)
  • 비트당 트랜지스터 많음 → 낮은 밀도·높은 비용
  • 용도: CPU L1/L2/L3 캐시

DRAM

트랜지스터 1개 + 커패시터 1개 (1T1C)

  • 커패시터 전하 누설 → 수십 ms마다 refresh
  • 이 refresh = 데이터센터 전력의 상당 부분
  • SRAM보다 훨씬 높은 밀도 · 용도: 메인 메모리
DNA와 대비되는 지점

SRAM·DRAM은 정보 유지를 위해 "계속 에너지를 써야 한다" · DRAM은 초당 수십 회 자체 재기록
DNA는 보관 중 에너지 소비 사실상 0 · 화학적 안정성 자체가 저장 메커니즘

NAND 플래시 — 밀도와 오류율의 교환

오늘 강의에서 가장 중요한 유비(analogy)

  • 원리: 플로팅 게이트 / charge trap 층에 전자를 가둬 문턱전압(Vt) 변경
    • 전원 없이 전하 유지 → 비휘발성
방식셀당 비트전압 준위밀도오류율 / 수명
SLC1 bit2단계×1최저 오류율·최장 수명
MLC2 bits4단계×2↓
TLC3 bits8단계×3↓↓

★ DNA에서 동일하게 반복되는 구조

아래쪽 계층 — HDD · 광디스크 · LTO 테이프

아카이브의 현실적 주력

HDD

회전 자성 원판 + 부상 헤드

  • 기계 부품 → 지연시간 ms 단위
  • 진동·충격에 취약
  • 계속 회전 → 전력 상시 소모
  • 용량당 단가는 낮은 편

광디스크 (M-DISC 등)

레이저로 기록층 반사율 변경

  • 무기물 기록층 → 수백 년 표방
  • 전력 없이 보관 가능
  • 용량·용량당 단가가 아카이브 규모에 부족

LTO 테이프

아카이브의 사실상 표준

  • $/TB 가장 낮음, 보관 중 전력 0
  • 세대마다 용량 약 2배씩 증가
  • 순차 접근 → 파일 하나에 수십~수백 초
  • 드라이브 호환 2~3세대 → 마이그레이션 강제
아카이브의 딜레마

LTO 저장 자체는 거의 공짜 · 문제 = "계속 살아있게 유지하는 비용" · 10년마다 전체 재기록, 사람·장비·위험 추가

STORAGE LIMITS

A. Extance, Nature (2017) — 세 매체의 정면 비교

  • 읽고 쓰는 속도 — DNA도 나쁘지 않다?
    • 비트 단위 비교는 타당 · 문제 = 처리량·준비 시간
  • 데이터 보존 — >100년

  • 데이터 밀도 — ~10¹⁹ bits/cm³
    • 플래시(~10¹⁶)보다 1,000배, HDD(~10¹³)보다 100만 배.

"1 kg의 DNA"

정보밀도

주어진 값

  • 뉴클레오티드 평균 분자량 ≈ 325 g/mol
  • nt당 정보 이론 상한 = 2 bits (4염기 = 2²)
  • 아보가드로 수 = 6.022 × 10²³ /mol

계산

(1 g ÷ 325) × 6.022×10²³ ≈ 1.85 × 10²¹ nt
1.85×10²¹ × 2 bits = 3.71 × 10²¹ bits
= 4.63 × 10²⁰ byte ≈ 463 EB/g

⚠️ 이론 상한

실제 시스템에서 빠지는 것들

  • 프라이머 결합부위 (양쪽 각 ~20 nt)
  • 인덱스 / 주소 영역
  • 오류정정 중복분 (원본 대비 +30~50%)
  • GC·호모폴리머 제약에 의한 코딩 효율 손실
  • 각 서열을 여러 카피로 합성 (coverage)

→ net density = 보통 1.0~1.8 bits/nt

PART 5

DNA 구조와
정보 표현

Structure & Information Encoding

  • 화학 구조와 방향성 — 왜 5′→3′이 중요한가
  • 상보성·이중나선과 기하학적 수치
  • 4염기 = 2 bits, 그러나 공짜가 아닌 이유

DNA 화학 구조 복습

뉴클레오티드 = 당 + 인산 + 염기

  • ① 디옥시리보스 (5탄당)
    • 2′ 위치에 OH 없음 — RNA와의 결정적 차이 · DNA 안정성 우위
  • ② 인산기
    • 음전하 → 전기영동 분리·전기장 조작 가능
  • ③ 염기 — 퓨린(A, G) / 피리미딘(C, T)
    • 정보를 담는 부분 · 나머지 둘은 "골격"

★ 방향성 — 필수 기억

포스포디에스테르 결합: 한 뉴클레오티드의 3′-OH와
다음 뉴클레오티드의 5′-인산 연결

→ DNA 가닥 방향: 5′ 말단 → 3′ 말단

자연의 DNA 중합효소: 5′ → 3′ 방향으로만 합성

화학적 포스포라미다이트 합성: 3′ → 5′ 방향

이 방향 차이 = 6장(화학적 합성)과 7장(효소적 합성)의 분기점

생명분자가 정보분자의 활용

DNA = "그냥 4진수 문자열" · 그러나 저장 한계(길이 제한·호모폴리머·합성 방향)는 모두 이 화학에서 기원
분자 구조 이해 → 200 nt 길이 한계 이해

상보성 · 이중나선 · 기하학적 수치

DNA 부피 밀도의 기하학적 근거

A = T · 수소결합 2개

G ≡ C · 수소결합 3개

→ GC 함량 증가 → Tm(녹는점) 상승

B-form DNA 기하

  • 염기쌍 간 거리 ≈ 0.34 nm
  • 나선 피치 ≈ 3.4 nm (약 10.5 bp)
  • 이중나선 지름 ≈ 2 nm
두 가닥의 역평행성(antiparallel)

한 가닥이 5′→3′이면 짝은 3′→5′ · 프라이머 방향 오류 시 증폭 불가

밀도 계산의 출발점

굵기 2 nm, 길이 방향 0.34 nm/bp에 2 bits → 비트당 부피 약 1 nm³
최신 3D NAND의 비트당 부피와 비교 필요 · "10¹⁹ bits/cm³"의 물리적 근거

4염기 = 2 bits의 대가

생물학적 제약에 따른 코딩 효율 감소

제약내용왜 문제가 되는가
호모폴리머동일 염기 연속 ≤3개합성 결실·나노포어/pyrosequencing 길이 오류
GC 함량40~60% 유지저GC: 낮은 Tm·불안정 프라이밍 / 고GC: 이차구조·합성 난도 증가
이차구조헤어핀·자기상보 서열 회피PCR·시퀀싱 방해
금지 motif제한효소·프라이머 유사 서열 회피비의도 절단·교차반응
서열 유사성올리고 간 충분한 편집거리클러스터링·디코딩 혼동
[퀴즈] 사고 문제

호모폴리머를 최대 3개로 제한하면 nt당 정보량의 이론 상한은 2 bits보다 얼마나 줄어드는가?
힌트: 제약을 만족하는 서열의 개수를 세는 문제 → 점화식과 채널 용량

코딩 이론의 필요성

제약 준수와 정보 밀도 최대화 = 3장(인코딩)·4장(ECC)·5장(해시·분수코드)의 전부
오늘 목표 = "왜 필요한지" 이해

오늘의 정리

1강 + 2강 핵심 여섯 문장

  1. 저장 매체 역사 = 밀도·비용 확보와 수명·내구성 상실의 반복
  2. 데이터는 ZB 단위 폭증 / 대부분은 거의 읽지 않는 콜드 데이터
  3. 테이프 아카이브 근본 문제 = 주기적 마이그레이션·포맷 진부화
  4. DNA: 밀도·수명·에너지·포맷 영속성 우위 / 쓰기 비용·속도 열세
  5. DNA 저장 = 인코딩→합성→보존→접근→시퀀싱→디코딩의 6단계 통신 채널 문제
  6. 용량 폭증 / 밀도는 2 bits/nt에서 정체 · 다음 돌파구 = 화학·공정·시스템
