PART 1

크로마토그래피 기초

Chromatography Basics

  • 크로마토그래피는 무엇으로 물질을 나누는가
  • 정성분석과 정량분석은 어떻게 다른가
  • GC 대신 HPLC를 쓰는 이유는 무엇인가

용어 정리 — -graphy · -graph · -gram

이동상 + 정지상 = 분리

6,000 psiHPLC (High Performance LC)
처음 이름은 High Pressure LC
→
15,000 psiU(H)PLC (Ultra High Performance LC)
입자 더 작게 · 압력 더 높게

  • Chromatography — 기법·학문 자체 (-graphy)
  • Chromatograph — 분석 장비 (gas chromatograph, liquid chromatograph)
  • Chromatogram — 결과 그래프 · x축 머무름 시간(min) · y축 신호 크기
HPLC의 유래

컬럼에 정지상을 채우고 이동상을 흘리는 컬럼 크로마토그래피에 압력을 세게 가했더니 분리가 훨씬 좋아짐 → High Pressure → High Performance

정성분석과 정량분석

표준물질의 머무름 시간으로 '무엇', 피크 면적으로 '얼마나'

  • 정성분석 — 표준물질과 미지 시료를 동일 조건에서 분석
    • 표준 A 4.5분, B 7.4분 → 미지 시료의 4.5분·7.4분 피크 = A, B
  • 정량분석 — 피크 면적(또는 높이) 비교
    • 20 ppm 표준 면적 20 → 미지 시료 면적 12 → 12 ppm
    • 성분마다 검출기 감도가 달라 같은 농도라도 면적이 다름
검정곡선 (calibration curve)

x축 농도, y축 감응 · 여러 농도를 찍어 최소제곱법으로 y = ax + b · 미지 시료의 감응값 → 농도 · 정량 전에 반드시 정성이 선행

GC vs. HPLC

이동상이 다르면 머무름 조절 방법과 분석 대상이 달라진다

기기이동상머무름 조절분자량휘발성극성도열적 안정성
GC기체컬럼 온도 (실온 ~ 330 ℃)낮은 것 (약 300 이하)높은 것만비극성안정한 것만
HPLC액체이동상 조성 (극성도)낮은 것 ~ 높은 것낮은 것도 가능극성 · 비극성불안정한 것도 가능
  • GC는 주입구·컬럼·검출기가 200~300 ℃ → 그 온도에서 휘발하고 열에 안정한 화합물만 분석
  • HPLC는 상온 부근에서 작동 → 비휘발성·열에 불안정한 물질, 분자량이 큰 물질도 분석
결론

유기화합물 중 HPLC가 커버하는 범위가 GC보다 훨씬 넓다 · 그래서 실험실에는 GC보다 HPLC가 훨씬 많다

PART 2

HPLC 시스템과 용리

System & Elution

  • 기기는 어떤 세 부분으로 되어 있는가
  • 왜 어떤 물질은 빨리, 어떤 물질은 늦게 나오는가
  • 머무름 시간은 무엇으로 조절하는가

HPLC 기기의 구성

송달부 · 분리부 · 검출부

흐름 — 이동상 용매 → 펌프 → 주입구 → 컬럼 → 검출기 → 폐용매

  • 송달부 — 펌프가 이동상을 밀어 주입구로 보냄
    • 액체는 가만히 두면 흐르지 않으므로 펌프가 필수
  • 분리부 — HPLC 컬럼에서 성분 분리
  • 검출부 — 검출기 → 컴퓨터, 이동상은 폐용매로
흐름

이동상 용매 → 펌프 → 주입구(시료 합류) → 컬럼(분리) → 검출기(피크) → 폐용매

왜 머무름 시간이 다른가

비극성 정지상(C18)에서 용질의 극성도 차이 — like dissolves like

핵심 문장

용질이 정지상보다 이동상에 더 많이 분배되어 있으면 → 머무름 시간은 짧아진다 · 비극성 물질 A는 C18에 붙잡혀 늦게, 극성 물질 B는 이동상에 실려 먼저

머무름 시간은 어떻게 조절되는가

용매 분자(◆)와 용질 분자(●)가 정지상을 두고 경쟁한다

용매–용질 경쟁과 머무름 시간

  • 극성 이동상 — 비극성 정지상에 침투 못 함 → 용질이 정지상에 남음
  • 비극성 이동상 — 정지상에 파고들어 용질을 밀어냄 → 이동상 쪽 분배 증가
    • 예: 극성 이동상에서 7.0분 → 비극성으로 바꾸면 5.0분
  • 용리 서열 — 흡착제에서 용질을 치환시키는 용매의 상대적 능력
역상(C18)의 규칙

용매의 극성 감소 → 용리액 세기 증가 → 용질은 컬럼에서 더 빨리 용리 · 물:메탄올 = 70:30이면 극성↑ 머무름↑, 30:70이면 극성↓ 머무름↓

역상 크로마토그래피에서 이동상 용매의 영향

극성도 순서 = 용리 세기의 역순

역상 HPLC의 실제 이동상

물 + 메탄올 / 아세토나이트릴 / THF

물이 가장 극성(용리 세기 최소) · 유기용매 비율을 올릴수록 빨리 나온다

실험실 표기: MeOH · ACN · THF · IPA · EA · MC

왜 서열을 알아야 하나

같은 분리를 메탄올 대신 ACN이나 THF로 옮길 때, 그리고 기울기 용리 설계에서 어느 용매가 '센' 용매인지 알아야 한다 (PART 6)

시료 주입부

Injector

  • 어떤 상태로, 얼마나, 어떤 농도로 주입하는가
  • 6-port 밸브는 어떻게 정확한 부피를 넣는가
  • 바이알·인서트·오토샘플러

주입 조건 — 상태 · 양 · 농도 · 용매

액체 시료를, 아주 조금, 이동상과 섞이는 용매에 녹여서

10–20 µLHPLC 주입량
컬럼 dead volume의 1~5 %
1–5 µLUPLC 주입량
아주 소량으로 충분
1–100 µg/mLUV/Vis 검출 적정 농도
= 1~100 ppm
  • 액체 시료 — 분석물질이 용매에 녹은 용액 상태로 주입 · HPLC는 물에 녹여도 됨 (GC는 불가)
  • 농도 — 1 ppm 이하는 검출이 어렵고, 100 ppm 초과는 피크 정점이 잘림(overload) → 정량·정성 모두 불가
  • 시료 용매 — 이동상과 잘 섞이는 용매 (역상: 물·메탄올·아세토나이트릴) · 에테르에 녹이면 이동상에 떠서 분리 실패
실무 팁

수돗물처럼 깨끗한 수용액 시료는 필터만 하고 그대로 주입 가능 · 시료는 가능하면 이동상 자체에 녹이는 것이 가장 좋은 피크를 준다

6-port 밸브 — 시료 적재와 주입

루프 부피가 주입량을 결정한다

6-port 밸브의 두 상태

  • (a) 시료 적재 loading — 이동상은 4→5→컬럼으로 흐름
    • 루프가 20 µL면 주사기로 25 µL를 1번 포트에 주입 → 20 µL만 루프에, 나머지는 폐기
  • (b) 시료 주입 inject — 밸브를 돌리면 이동상이 4→3→루프 통과
    • 루프 속 시료를 밀어 6→5→컬럼으로 보냄
  • 수동 주입이든 오토샘플러든 원리는 같다
왜 루프보다 많이 취하나

루프를 완전히 채워야 주입 부피가 재현된다 · 항상 루프 부피보다 넉넉히 취해 넘치는 양은 폐기시킨다

바이알 · 인서트 · 오토샘플러

시료가 적을 때와 자동 주입

  • 샘플 바이알 — 보통 1.5 mL
  • 인서트 — 시료가 200 µL 정도로 적을 때(생체 시료) 바이알 안에 끼우는 뾰족한 유리관
    • 없으면 바닥에 깔려 오토샘플러가 취하지 못함
  • 오토샘플러 — 프로그램에 주입량 입력 → 기계 주사기가 샘플링·주입
요즘의 표준

대부분 오토샘플러 사용 · 수동 주입(25 µL 주사기)도 원리는 동일

컬럼

The Column

  • 컬럼은 어떻게 생겼는가
  • 정지상은 실리카 위에 어떻게 만들어지는가
  • 입자 크기는 무엇을 바꾸는가

컬럼의 형태

내경 2.1~4.6 mm · 입자 1.8~5 µm · 길이 50~300 mm

  • 재질 — 스테인리스 강철(대부분) 또는 플라스틱
  • 분석 컬럼 vs 분취(prep) 컬럼 — 분취는 많은 양을 주입해 fraction으로 구획(천연물 화학)
  • 구조 — 입구 쪽 보호 컬럼, 양 끝 다공성 타이타늄 프릿, 주 컬럼, 알루미늄 재킷

왜 pH 범위인가

실리카 기반 정지상은 이동상 pH가 범위를 벗어나면 녹거나(염기성) 실란올이 해리되어 꼬리끌림(산성)을 만든다

정지상 (Stationary Phase)

고체 지지체 = 고순도 · 구형 · 미공성 실리카 입자

  • 실리카 표면 — 1 m²당 최대 8 µmol의 실란올(Si–OH) 노출
  • pH 8 이상 — 실리카가 해리(용해) → pH 8~12 염기성 화합물은 폴리스티렌 같은 고분자 지지체
  • pH 2~3 — 실란올이 Si–O⁻로 해리 → 노출된 기가 꼬리끌림(tailing) 유발
  • 실란올을 변형(modify)해 원하는 정지상을 만든다 · 실리카 = 지지체, 붙인 것 = 정지상
안전한 이동상 pH

실리카 기반 컬럼은 pH 약 3~8 (제조사 표기 2.0~7.5) 범위에서 사용 · 피크는 가우시안이어야 정량·정성이 정확

실리카 표면과 두 종류의 크로마토그래피

흡착 vs 액체-액체 분배

흡착 크로마토그래피

실리카 입자 표면의 Si–OH와 직접 상호작용 · 유기합성·천연물 화학의 오픈 컬럼

액체-액체 분배 크로마토그래피

실리카 표면의 실란올기에 붙인 정지상(C18 등)에서 분배 · 일반적인 HPLC 조건

실란올의 종류

고립(isolated) · 수소결합한 인접(vicinal) · 제미날(geminal) 실란올과 실록산 결합 — 결합되지 않고 남은 잔류 실란올이 PART 7의 '첨가제' 문제로 이어진다

결합 정지상의 제조와 종류

Si–OH + ClSi(CH₃)₂R → Si–O–Si(CH₃)₂R · R기가 극성을 결정

극성 정지상 (R = 극성기)비극성 정지상 (R = 탄화수소)
AminoOctadecyl (C18) · R = (CH₂)₁₇CH₃
CyanoOctyl (C8) · R = (CH₂)₇CH₃
DiolPhenyl
  • 극성 정지상 — Amino, Cyano, Diol
  • 비극성 정지상 — Octadecyl(C18), Octyl(C8), Phenyl
  • C18 > C8 > C4 > Cyano > Phenyl > Amino 순으로 소수성 감소 · 극성 증가
    • 비극성 분석물질은 C18에서 머무름 최대, Amino·Phenyl에서 빨리 나옴
참고

정지상은 실험실이 아니라 제조사가 만들어 판매한다

전형적인 역상 정지상 — C18 컬럼의 구조

분석물질의 비극성 부분과 C18 사슬의 소수성 상호작용

  • 고체 지지체(Si)에 탄소 18개 사슬을 결합
  • 분석물질의 비극성 부분이 C18과 소수성 상호작용 → 머무름
  • 결합되지 않은 OH(잔류 실란올)도 남아 있다
연결

잔류 실란올은 염기성 화합물과 2차 상호작용 → 꼬리끌림 · 해결책은 pH 조절과 희생 염기(PART 7)

입자 크기의 영향

작은 입자 = 고효율, 그러나 고압력

  • 10 µm → 5 µm: 숨어 있던 분해 산물 피크가 분리됨
  • 전형적인 입자 크기 3~10 µm · 일반 HPLC 최대 약 6,000 psi (≈ 400 기압)
van Deemter

흐름 속도가 높아도 입자가 작을수록 이론단 높이가 작게 유지 → 분리능 증가

컬럼의 이상 징후와 보관

초보자가 놓치는 신호들

이상 징후

  • ✓ 피크 모양이 찌그러짐 (꼬리끌림·갈라짐)
  • ✓ 머무름 시간 변화 (7.0분 → 6.2분)
  • ✓ Backpressure 급증 (3,000 → 4,500 psi)
  • ✓ 피크 분리가 안 됨
  • ✓ Ghost peak 출현

보관

  • ✓ 실온 보관 — 냉장고·오븐 금지
  • ✓ 몇 시간~하룻밤: 직전 용매 그대로
  • ✓ 2일~1주일: 정제수로 워싱 (미생물·곰팡이 방지)
  • ✓ 장기: 물 50 % 이상 안 되는 용매(70 % MeOH)로 채움
  • ✓ end plug를 손으로 단단히 — 용매 휘발 방지
취급

떨어뜨리거나 충격 금지 · 권고 압력 한계 내 작동 · 규격에 맞는 너트·페룰·피팅만 · end fitting은 렌치 대신 손으로

컬럼의 효과적인 사용법

체크리스트 10

  1. 이동상 흐름이 화살표 방향과 일치하도록 설치
  2. 이동상은 탈기(degassing) + 0.45 µm 필터
  3. 보관 용매(IPA)와 호환되는 이동상으로 평형(equilibration) · 5~10배 부피
  4. 잔류 완충제·이온쌍 시약 제거 후 보관 — 염 석출 방지
  5. 실리카 컬럼 사용 pH 2.0~7.5
  1. 이동상 변경은 극성도가 점진적으로
  2. 과도한 압력 → reverse flush
  3. 모든 시료는 0.45 / 0.2 µm 필터 후 주입
  4. 주입구와 본 컬럼 사이에 guard 컬럼 — 소모품, 1~2달마다 교체, 본 컬럼과 같은 C18
  5. 시료는 이동상에 녹이는 것이 최선 · 불가하면 극성도 유사 용매
PART 6

이동상

The Mobile Phase

  • 용매는 어떤 등급을, 어떻게 다루는가
  • 정상과 역상에서 '센 용매'는 무엇인가
  • 등용매 용리와 기울기 용리는 언제 쓰는가

용매 (Solvent) — 등급 · 필터 · 탈기

컬럼 손상과 UV 바탕신호를 막으려면

  • HPLC grade 용매 · 물은 3차 정제수
    • 컬럼 손상 방지 + UV 바탕신호 감소
  • 용매 거름장치로 필터 — 유기용매용/수용액용 필터 구분, 진공 시 트랩 필수
  • 기체 방울 — 필터, (가열), He 디개싱으로 제거
  • 컬럼 세척은 평상시 사용 용매로
역상 재평형

초기 용매로 빈 컬럼 부피의 10~20배를 통과 · 재평형은 분리에 걸리는 시간만큼 소요

용매병과 흡입 필터

펌프보다 위에 두고 프릿을 통해 끌어내린다

이중 필터

필터링해 채운 이동상이 병 속 Sinker Frit을 한 번 더 지나 펌프·컬럼으로 들어간다

정상(NPLC) vs 역상(RPLC)

어느 쪽이 '센 용매'인가 — 반대다

정상 크로마토그래피 NPLC

Normal phase

극성 정지상 + 극성이 적은 용매

용리 세기는 극성 용매일수록 증가

비극성 n-hexane, n-heptane + 극성 isopropanol, chloroform, ethyl acetate 혼합으로 극성도 조절

역상 크로마토그래피 RPLC

Reversed phase · C18

비극성(약극성) 정지상 + 더 극성인 용매

용리 세기는 극성이 적은 용매일수록 증가

극성인 물 + MeOH, ACN, THF 같은 비극성 용매 혼합으로 극성도 조절

극성도 순서

Water > MeOH > IPA > ACN > EA > THF > MC > Chloroform > Isooctane > Hexane · 두세 가지 용매를 섞어 극성도를 맞춘다

RPLC에서 용매의 세기

극성도 P′와 용리 세기 ε⁰ · 용매를 바꿔도 같은 세기를 맞추는 눈금

  • 극성도: 물 10.2 · MeOH 5.1 · ACN 5.8 · THF 4.0
  • ε⁰(C18): MeOH 1.0 · ACN 3.1 · THF 3.7 → 오른쪽일수록 센 용매
예

문헌이 ACN:물 = 60:40이면 같은 용리 세기는 메탄올 약 70 %, THF 약 45 %

PART 7

pH · 완충용액 · 첨가제

pH, Buffers & Additives

  • 분석물질은 물에서 어떤 형태로 존재하는가
  • 완충용액은 무엇을, 얼마나, 어떻게 쓰는가
  • 첨가제와 희생 염기는 왜 필요한가

어느 것이 주 화학종인가

산·염기·중성형 — Henderson–Hasselbalch 식으로 예측

HA + H₂O ⇌ A⁻ + H₃O⁺
Ka = [H₃O⁺][A⁻] / [HA] pKa = −log Ka
pH = pKa + log([A⁻] / [HA])
  • 유기화합물 대부분은 산·염기성 → 물에서 해리 HA ⇌ A⁻ + H⁺
    • 중성형 HA (COOH) vs 이온형 A⁻ (COO⁻)
  • pH = pKa → [A⁻]:[HA] = 1:1 (벤조산 pKa 4.20)
  • pH = pKa + 1 (5.20) → 10:1 · pH = pKa − 1 (3.20) → 1:10
요점

수용액의 pH를 조정하면 분석물질을 중성형으로도, 이온형으로도 만들 수 있다 · 이온형은 극성이 커서 역상에서 빨리 나오고 꼬리끌림을 만들기 쉽다

pH에 따른 이온화 — 산과 염기는 반대

pKa ± 2 단위면 사실상 100 %

  • Homovanillic acid — COOH pKa 3.74, 페놀 OH pKa 9.95
    • pH 3 (a) 비해리 · pH 6~8 (b) COO⁻만 · pH 13 (c) 완전 해리
규칙

산: pH↑ 이온화 / 염기: pH↓ 이온화 · 작용기별 pKa(카르복실산 0.65~4.76, 아민 4.7~38 …) 표 참고

완충용액 (Buffer solution)

소량의 산·염기가 들어와도 pH가 크게 변하지 않게

완충용액의 농도와 취급

25~100 mM · 수용액 pH 먼저 · 미생물 · 세척

25–100 mMHPLC 완충용액 농도

  • pH 변화 원인: CO₂ 유입, 유기용매 증발, 시료 희석제

첨가제와 희생 염기

양성자화된 염기 + 잔류 실란올 = 꼬리끌림

  • 첨가제 — 완충용액은 아니지만 이동상 pH를 바꾸는 화합물
    • TFA(0.3), 인산(2.14/7.20/12.33), 시트르산, 포름산(3.75), 아세트산(4.76), TEA(10.21) …
  • 문제 — NH₃⁺ 형태의 염기가 잔류 실란올(Si–O⁻)과 2차 상호작용 → 머무름 길어지고 피크 왜곡
  • 해법 1 — pH를 올려 중성형(NH₂)으로 · 그러나 실리카 컬럼은 pH 2.5~7 한계
  • 해법 2 — 희생 염기 TEA, piperazine, TMEDA, DMOA 첨가

희생 염기의 작용

  • TEA 0 → 40 mM: As 4.2 → 1.2 · 불량(4, 2) / 양호(1.2) / 우수(1.0~1.05)

오늘의 정리

HPLC의 원리 여섯 문장

  1. 크로마토그래피 = 이동상과 정지상 사이의 분배 · HPLC는 액체 이동상 + 고압(6,000 psi)
  2. 정성 = 표준물질 머무름 시간 일치 · 정량 = 피크 면적 + 검정곡선
  3. 주입은 액체 시료 10~20 µL, 1~100 ppm · 6-port 밸브 루프가 부피를 결정
  4. C18 실리카 정지상: 소수성 상호작용 · pH 3~8 · 입자 작을수록 고효율·고압 · 세정은 이동상 부피 20배
  5. 역상에서 용매 극성↓ = 용리 세기↑ · 여러 성분은 기울기 용리 · 재평형 필수
