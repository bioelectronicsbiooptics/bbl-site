STORAGE LIMITS — 세 매체의 정면 비교

A. Extance, Nature (2017) · "DNA could store all of the world's data in one room"

읽는 법

표의 4행 중 DNA가 지는 것은 "속도" 하나뿐 · 나머지 셋(보존·전력·밀도)은 자릿수 단위로 이김 → 콜드 아카이브에 최적

"1 kg의 DNA" — 직접 계산

정보밀도의 이론 상한을 스스로 유도

주어진 값

  • 뉴클레오티드 평균 분자량 ≈ 325 g/mol
  • nt당 정보 이론 상한 = 2 bits (4염기 = 2²)
  • 아보가드로 수 = 6.022 × 10²³ /mol

계산

(1 g ÷ 325) × 6.022×10²³ ≈ 1.85 × 10²¹ nt

1.85×10²¹ × 2 bits = 3.71 × 10²¹ bits

= 4.63 × 10²⁰ byte ≈ 463 EB/g

→ 연간 생성 데이터 200 ZB ≈ 400 g 남짓 · "1 kg"은 과장이 아님

⚠️ 이론 상한 — 실제 시스템에서 빠지는 것

  • 프라이머 결합부위 (양쪽 각 ~20 nt)
  • 인덱스 / 주소 영역
  • 오류정정 중복분 (원본 대비 +30~50%)
  • GC·호모폴리머 제약에 의한 코딩 효율 손실
  • 각 서열을 여러 카피로 합성 (coverage)

→ net density = 보통 1.0 ~ 1.8 bits/nt

→ 연구 목표(파이오니어): 2 PB/g = 2 TB/mm³ (3차원 파일 기준)

[퀴즈 예고]

150 nt 올리고에서 양쪽 프라이머 20 nt씩, 인덱스 16 nt를 뺀 payload에 1.8 bits/nt를 적용하면 올리고 하나에 실제로 저장되는 정보는 몇 bit인가?

The Chemical Structure of DNA

염기 서열 + 음전하 골격 — 정보와 골격의 분리

Watson & Crick, 1953

  • 염기 4종 A·T·C·G의 서열 = 정보
  • 당-인산 골격 = 음전하(-) · 전기영동·전기장 조작의 근거
  • 연속된 염기서열로 유전 정보 저장 → 생명체 합성 (Central Dogma)
  • 화학적/효소적 합성 가능 — Building block, "레고 블록"처럼
저장 관점

정보(염기)와 골격(당·인산)이 분리되어 있음 · 골격의 음전하 덕분에 전극 위에서 DNA를 끌어당기고(hybridization) 밀어낼(release) 수 있음 → 전기장 합성 칩

DNA 화학 구조 복습

뉴클레오티드 = 당 + 인산 + 염기

  • ① 디옥시리보스 (5탄당)
    • 2′ 위치에 OH 없음 — RNA와의 결정적 차이 · DNA 안정성 우위
  • ② 인산기
    • 음전하 → 전기영동 분리 · 전기장 조작 가능
  • ③ 염기
    • 퓨린(A, G) / 피리미딘(C, T) · 정보를 담는 부분

★ 방향성 — 필수 기억

포스포디에스테르 결합: 3′-OH ↔ 다음 5′-인산

→ DNA 가닥 방향: 5′ 말단 → 3′ 말단

자연의 DNA 중합효소: 5′→3′ 방향으로만 합성

화학적 포스포라미다이트 합성: 3′→5′ 방향

이 방향 차이 = 6강(화학 합성)과 7강(효소 합성)의 분기점

왜 지금 짚는가

컴퓨터공학 전공자에게 DNA = "4진수 문자열" · 그러나 저장 한계(길이 제한·호모폴리머·합성 방향)는 모두 이 화학에서 기원

상보성 · 이중나선 · 기하학적 수치

DNA 부피 밀도의 기하학적 근거

A = T

수소결합 2개

  • B-form DNA 기하
    • 염기쌍 간 거리 ≈ 0.34 nm · 나선 피치 ≈ 3.4 nm (약 10.5 bp) · 지름 ≈ 2 nm
  • 두 가닥의 역평행성(antiparallel)
    • 한 가닥이 5′→3′이면 짝은 3′→5′ · 프라이머 방향 오류 시 증폭 불가
  • 밀도 계산의 출발점
    • 굵기 2 nm × 길이 0.34 nm/bp에 2 bits → 비트당 부피 약 1 nm³ = "10¹⁹ bits/cm³"의 물리적 근거

G ≡ C

수소결합 3개 → GC 함량↑ = Tm(녹는점)↑

DNA Hybridization — 선택적 결합

DNA의 기능 ① : 짝이 맞는 서열끼리만 붙음

  • 단일가닥 probe + 상보 서열 → 이중가닥 형성 (annealing)
  • 완전 일치(perfectly matched) vs 불일치(mismatched) — 결합 안정성 차이
    • 온도(Tm)·염 농도·GC 함량이 결합 강도 결정
  • 저장 시스템에서의 쓰임
    • 프라이머가 목표 파일 서열에만 결합 → random access (9강)
    • 마이크로어레이·전극 칩 위 서열 포획 → 전기장 hybridization 합성 (파이오니어 핵심 기술)
    • DNA 컴퓨팅·DB 검색 — hybridization 자체가 "비교 연산"
한 줄 요약

hybridization = 분자 수준의 "검색 연산" · 수백만 종 서열이 섞인 한 방울에서 원하는 것만 골라내는 유일한 물리적 수단

PCR — 복제 비용 0

DNA의 기능 ② : 프라이머 결합으로 유도하는 지수 증폭

  • 3단계 사이클: 변성(95 °C) → 결합(annealing, 50~65 °C) → 신장(72 °C)
  • 사이클마다 2배 → 30 사이클이면 2³⁰ ≈ 10⁹배
  • 프라이머 = 시작점 지정 · 앞뒤 20 nt 서열이 "파일 주소" 역할
  • 저장 관점의 의미
    • 읽기 전 증폭 → 시퀀싱에 필요한 양 확보
    • 사본 만들기 ≈ 무료 · 백업·배포가 물리적으로 쉬움
    • 대신 편향(bias)·오류 누적 → 반복 읽기의 한계 (PART A 한계표)
[계산]

1 fg(10⁻¹⁵ g)의 DNA를 30 사이클 증폭하면 이론상 약 1 µg · "한 방울"에서 "시퀀서에 넣을 양"으로 — 이것이 파괴적 읽기를 견디는 이유

200 nt에서 0.995²⁰⁰ ≈ 37%만 온전

    • 유전자 합성기는 "정확한 긴 서열 소량" 최적 · 메모리는 "짧은 서열 수백만 종 초저가" 필요

합성 비용과 속도 — 상용화의 진짜 관문

DNA 메모리 합성 비용 · 속도 · 목표

비용

  • 염기 1개 합성: 15달러(2001) → 7센트(2017) → 0.5센트 목표(2027)
  • 1 MB당 약 3,500달러(현재) → 2,100달러 전망 · HDD $0.02/GB와 6~8자릿수 차이
  • 파이오니어 목표: 500원/GB (합성 기준) · IARPA MIST: 1 PB/chip, $1/TB (2030)

속도

  • 화합물 기반 합성: 주문생산 방식 1일~3주
  • 효소 기반 합성: 이론상 < 100 µs/bit · Catalog 1 TB/24 h (2019)
  • 데이터 "복사"는 PCR 기반 합성으로 — 쓰기와 복사를 분리

왜 비용이 안 떨어지는가

  • 시퀀싱 비용은 20년간 10⁶배 하락 · 합성 비용은 10²배에 그침 (왼쪽 위 그래프)
  • 합성은 "한 분자씩 화학 반응" · 반도체처럼 병렬화·소형화해야 곡선이 꺾임
핵심

읽기(시퀀싱)는 이미 싸졌고, 쓰기(합성)가 병목 · 그래서 이 분야의 하드웨어 연구 = 거의 전부 "합성 장치"

효소 기반 합성의 대두

Terminal deoxynucleotidyl Transferase (TdT) — 물 속에서, 상온에서, 5′→3′로

Nature Biotechnology (2018) Table 1 — 효소적 DNA 합성 기업

  • TdT = 주형 없이 3′ 말단에 뉴클레오티드를 붙이는 효소
    • 보호기가 달린 dNTP(예: dNTP-N₃)를 한 번에 하나씩 → 탈보호 → 반복
  • 화학 합성 대비 장점
    • 독성 용매 불필요 · 수용액·상온 · 긴 서열(1 kb 이상) 가능성
    • 전극·칩 위에서 직접 합성 → 데이터 "쓰기 헤드"로 적합
  • 기업: DNA Script · Molecular Assemblies · Nuclera · Ansa · Camena · Kern
  • 파이오니어 과제: Klenow → T4 Ligase → TdT 단계별 도입

오늘의 정리

제2강 핵심 여섯 문장

  1. 생성 데이터의 0.5%만 저장 가능해지는 시대 · 밀도·전력·수명에서 자릿수 개선이 필요
  2. DNA: 밀도·수명·에너지·포맷 영속성 우위 / 쓰기 비용·속도 열세 → 동결 아카이브 계층
  3. DNA의 기능 = 상보성(hybridization = 검색) + PCR(복제 비용 0) + 음전하 골격(전기장 조작)
  4. DNA 저장 = 인코딩→합성→보존(접근)→시퀀싱→디코딩의 5단계 통신 채널 문제
  5. 용량은 KB→MB→수백 MB로 폭증 / 밀도는 2 bits/nt에서 정체
  6. 읽기는 싸졌고 쓰기(합성)가 병목 · 다음 돌파구 = 칩·효소·시스템 공학
