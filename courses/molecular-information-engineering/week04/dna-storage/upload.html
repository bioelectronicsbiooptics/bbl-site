FASTA 파일과 복호 설정 준비

학생 정보를 입력하고 Encoding 결과 FASTA/TXT를 선택하면, MATLAB 디코더 맨 위에 넣을 설정 코드를 만들어 줍니다. 만든 코드를 복사해 MATLAB Online에서 실행하세요.

이름·학번 입력 → FASTA/TXT 확인 → MATLAB 설정 코드 복사 → MATLAB Drive에 FASTA와 디코더를 두고 실행

이 페이지는 전송 폼이 아닙니다. 이름, 학번, 선택한 파일은 이 브라우저 안에서 설정 코드를 만들 때만 사용하며 사이트·NAS로 업로드되지 않습니다. 실제로 NAS에 제출하는 절차가 필요하면 별도의 승인된 업로드 서비스를 연결해야 합니다.

파일은 브라우저에서 형식만 확인합니다. 최대 50 MB.

Encoding 출력 로그의 D 값

예: txt, jpg, png

MATLAB에 붙여 넣을 코드

  1. 선택한 FASTA/TXT를 MATLAB Drive의 작업 폴더에 올립니다.
  2. 선택한 디코더 파일을 열고 맨 위 설정에서 inFile, L, D, ext를 아래 값으로 바꿉니다.
  3. 전체 디코더 파일을 Run합니다. 디코더 설정 아래의 clear; clc;와 나머지 코드는 유지합니다.

Encoding 파일 만들기와 디코딩 흐름은 4주차 MATLAB 강의록을 참고하세요. 이 페이지는 NAS 제출을 처리하지 않습니다.
