오류정정부호(error-correcting code) — 정의 · 예제

일부 단어만 쓰기로 한 약속

정의 Definition
  • 부호화: message(k 기호) → codeword(n 기호) · 서로 다른 message → 서로 다른 codeword
  • 부호 C = 허용된 codeword의 집합 · (n, k) 부호
  • 검출: 수신어가 C에 없음을 판별 · 정정: 원래 codeword 추정
  • 부호율 R = k/n
예제 Example
  • 3회 반복: 0 → 000, 1 → 111
  • C = {000, 111} · 8개 단어 중 2개만 사용
  • 수신 010 ∉ C → 오류 검출
  • 가장 가까운 000으로 정정 → message 0

%% Lab 1 — BSC 채널과 3회 반복 부호 (툴박스 불필요)
p = 0.01;  N = 1e6;              % 오류 확률, 보낼 bit 수
u = randi([0 1], 1, N);          % message
c = repmat(u, 3, 1);             % codeword: 각 bit 를 3번 (3 x N)
e = rand(3, N) < p;              % BSC: 확률 p 로 뒤집힘
r = xor(c, e);                   % received word
u_hat = sum(r, 1) >= 2;          % 다수결 복호
fprintf('부호 없이  : 오류율 %.5f\n', mean(rand(1,N) < p));
fprintf('3회 반복   : 오류율 %.6f\n', mean(u_hat ~= u));
fprintf('이론 3p^2-2p^3 = %.6f\n', 3*p^2 - 2*p^3);

Hamming 무게와 Hamming 거리 — 정의 · 예제

무게 = 단어 하나의 값 · 거리 = 단어 두 개 사이의 값

정의 Definition
  • Hamming 무게(weight) wt(x): 벡터 x에서 0이 아닌 자리의 개수 · 이진 → 1의 개수
  • Hamming 거리(distance) d(x, y): 길이가 같은 두 벡터 x, y에서 값이 다른 자리의 개수
d(x, y) = wt(x ⊕ y)
  • 무게: 단어 하나 · 거리: 단어 두 개 사이
예제 Example
