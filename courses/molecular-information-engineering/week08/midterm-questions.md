## 6-1강 — DNA 고체상 화학 합성

### 문제 1. CPG의 정의와 사용 이유

CPG(Controlled Pore Glass, 세공 크기가 제어된 다공성 유리)의 구조적 특성과 DNA 화학 합성에서의 역할을 설명하시오. 사용 이유에 **비표면적, 시약의 접근, 컬럼 내 시약 공급과 배출**을 포함하시오. 또한 세공 크기와 합성 사슬 길이의 관계를 설명하시오.

### 문제 2. 한 표면 반응점의 분자 연결 구조

CPG의 한 표면 반응점에 고정된 두 잔기 길이의 DNA 사슬을 구조식으로 그리시오. 두 염기는 모두 Thymine(티민, T)으로 하시오.

- CPG–LCAA 스페이서–숙시닐 연결기–첫 잔기 3′-O의 연결 관계를 표시하시오.
- 두 디옥시리보스의 탄소 번호 1′–5′와 두 잔기 사이의 당–인산 연결을 표시하시오.
- 티민을 B 또는 T의 약칭으로 생략하지 말고, 고리·질소·카보닐기·메틸기를 그리시오.
- Oxidation(산화)이 끝난 상태를 기준으로 5′-DMT와 인산의 2-시아노에틸 보호기를 표시하시오.
- 사슬 신장 방향과 최종 회수 시 절단되는 에스터 결합을 표시하시오.

CPG 무기 골격, LCAA 장쇄 부분 및 DMT는 약칭 사용 가능. 염기·당·숙시닐 연결기·인산·2-시아노에틸기는 구조식으로 작성.

### 문제 3. 4단계 합성 사이클

Phosphoramidite(포스포라미다이트)를 이용한 DNA 고체상 합성의 **4단계 이름을 순서대로** 쓰시오. 각 단계의 영어 명칭과 괄호 안의 한글 명칭을 함께 쓰시오.

### 문제 4. Phosphoramidite의 보호기와 반응점

DNA 합성용 phosphoramidite 단량체에서 **5′-OH, 염기의 반응성 아미노기, 인산 부위**를 보호하는 이유를 각각 설명하시오. 또한 Coupling(커플링)에서 기존 사슬과 반응하는 단량체의 원자를 표시하시오. 염기 아미노기 보호는 Adenine(아데닌), Cytosine(사이토신), Guanine(구아닌)을 기준으로 설명하시오.

### 문제 5. 화학 합성과 생체 합성의 신장 방향

DNA 화학 합성과 생체 내 DNA 중합의 사슬 신장 방향을 각각 쓰시오. 화학 합성이 생체 합성과 반대 방향으로 진행되는 이유를 **고체 지지체에 고정된 말단, 기존 사슬의 자유 OH, 새 단량체의 연결 위치**를 이용하여 설명하시오.

### 문제 6. 산에 의한 DMT 제거

Detritylation(탈트리틸화)에서 산 처리로 5′-DMT가 제거되어 자유 5′-OH가 생성되는 과정을 설명하시오. TCA와 DCA의 영어 전체 명칭을 쓰고, 산의 세기·처리 시간과 Depurination(탈퓨린화)의 관계를 설명하시오. 수용액 pKa를 디클로로메탄 합성 용액의 pH와 동일하게 해석할 수 있는지도 설명하시오.

### 문제 7. Coupling과 Oxidation의 반응

Coupling(커플링)에서 **기존 사슬의 5′-OH와 새 단량체의 P(III)**가 어떻게 연결되는지 설명하시오. 이어서 Oxidation(산화)의 필요성과 인의 산화 상태 변화를 설명하시오.

### 문제 8. Capping과 결손 서열

Coupling(커플링)에 실패한 사슬의 미반응 5′-OH를 Capping(캡핑)하는 이유를 설명하시오. Capping을 생략한 경우와 수행한 경우를 비교하여, 다음 사이클의 연장 여부와 최종 불순물의 차이를 설명하시오.

### 문제 9. Cleavage and Deprotection과 부산물

Cleavage and Deprotection(절단과 탈보호)에서 **고체 지지체와의 연결, 염기 보호기, 인산의 2-시아노에틸 보호기**가 어떻게 처리되는지 설명하시오. 또한 Acrylonitrile(아크릴로니트릴)이 어느 보호기의 제거 과정에서 생성되는지 쓰고, 이 부산물이 티민의 변형을 일으킬 수 있는 이유를 설명하시오.

### 문제 10. Coupling 효율과 전장 산물 비율

첫 뉴클레오사이드가 고체 지지체에 미리 고정되어 있고, 매 Coupling(커플링)의 성공률이 99.5%로 일정하다고 가정하시오. 다른 손실과 부반응은 고려하지 않으며, 각 단계의 성공 여부는 독립이라고 가정하시오.

100-mer와 200-mer 합성에서 필요한 Coupling 횟수와 예상 전장 산물 비율을 각각 계산하시오. 같은 단계별 효율에서도 사슬 길이가 증가하면 전장 산물 비율이 감소하는 이유를 설명하시오. **계산기 사용 가능.**

## 6-2강 — 장치 기반 병렬 합성과 올리고 풀

### 문제 11. 주요 장치 기반 합성 방법 5가지

6-2강에서 다룬 **주요 장치 기반 DNA 병렬 합성 방법 5가지를 쓰시오.** 각 방법에서 위치별 반응을 선택하는 장치 또는 구조를 함께 쓰시오.

### 문제 12. Photomask-guided synthesis의 장치와 공정

Photomask-guided synthesis(포토마스크 광유도 합성)에서 **광원, 포토마스크, 합성 기판**의 역할을 설명하시오. 마스크 개구부 아래에서만 탈보호가 일어나는 이유와, 서로 다른 서열을 합성하기 위해 마스크를 교체하는 이유를 설명하시오.

### 문제 13. Maskless DMD synthesis의 장치와 공정

Maskless DMD synthesis(마스크리스 DMD 합성)에서 DMD(Digital Micromirror Device, 디지털 미세거울 장치)의 역할을 설명하시오. 거울의 ON/OFF 상태로 조사 위치를 선택하는 과정과 물리적 포토마스크 방식과의 차이를 설명하시오.

### 문제 14. Inkjet synthesis의 장치와 공정

Inkjet synthesis(잉크젯 합성)에서 **프린트헤드, 토출 좌표, 단량체 용액**의 역할을 설명하시오. 서로 다른 위치에 A·C·G·T를 도입하는 방법과, 광유도 합성에 비해 공간 선택성이 적용되는 반응 단계의 차이를 설명하시오. 합성 챔버에서 무수 조건을 유지하는 이유도 설명하시오.

### 문제 15. Electrochemical synthesis의 장치와 공정

Electrochemical synthesis(전기화학적 합성)에서 **전극 배열, 전해액, 전압 인가**의 역할을 설명하시오. 선택한 양극 부근의 산 생성이 DMT 제거로 이어지는 과정과, 인접 음극에서 양성자를 소모하여 반응 영역을 제한하는 이유를 설명하시오.

### 문제 16. Silicon microwell synthesis의 장치와 공정

Silicon microwell synthesis(실리콘 미세웰 합성)에서 **미세웰, 격벽, 웰별 시약 분배**의 역할을 설명하시오. 여러 서열을 동시에 합성하면서 인접 반응 구획의 시약 혼합을 줄이는 방법과, 표준 산 탈보호를 적용할 수 있는 이유를 설명하시오.

### 문제 17. 장치별 공간 선택성 비교

주요 합성 방법 5가지를 **반응 위치 선택 방식, 위치별로 제어되는 반응 또는 시약 전달, 인접 반응 구획의 간섭 요인**을 기준으로 비교하시오. 답은 표로 작성하시오.

### 문제 18. 두 광탈보호 방식의 차이

Photoacid generation(광산 발생) 방식과 Photolabile protecting group(광분해성 보호기) 방식의 탈보호 과정을 각각 설명하시오. **빛으로 직접 변하는 대상, DMT 사용 여부, 공간 선택성을 제한하는 요인**을 비교하시오.

### 문제 19. 컬럼 합성과 칩 합성의 산출물

컬럼 합성과 칩 기반 병렬 합성을 **동시에 합성하는 서열 종류 수, 서열당 산출량, 회수 형태**를 기준으로 비교하시오. DNA 데이터 저장에서 Oligonucleotide pool(올리고뉴클레오타이드 풀)을 사용하는 이유와, 서열별 산출량의 불균일이 판독 누락으로 이어질 수 있는 이유를 설명하시오.

### 문제 20. 올리고 풀의 정제

Desalting(탈염), HPLC(고성능 액체 크로마토그래피), PAGE(폴리아크릴아마이드 겔 전기영동)의 분리 원리를 각각 쓰시오. 단일 서열 올리고와 수만 종 이상의 올리고 풀에서 정제법을 선택할 때 **불순물의 종류, 서열당 양, 서열별 분리·회수**를 어떻게 고려해야 하는지 설명하시오.

## 7-1강 — 효소 합성과 유전자 조립

### 문제 21. TdT의 역할과 주형 비의존적 합성

TdT(Terminal deoxynucleotidyl transferase, 말단 디옥시뉴클레오타이드 전이효소)의 역할을 설명하시오. 주형 의존 DNA 중합효소와 비교하여 **주형의 필요 여부, 뉴클레오타이드가 도입되는 말단, 사슬 신장 방향**을 쓰시오. 자유 dNTP를 공급하는 것만으로는 설계한 서열을 한 염기씩 합성하기 어려운 이유도 설명하시오.

### 문제 22. TdT–dNTP conjugate의 단일 잔기 도입

TdT–dNTP conjugate(효소–뉴클레오타이드 결합체)를 이용한 합성에서 한 염기를 도입한 뒤 추가 연장이 억제되는 이유를 설명하시오. **프라이머, 도입된 뉴클레오타이드, 절단성 linker, TdT**의 연결 관계를 간단한 도식으로 그리시오. 3′-OH가 차단되지 않은 상태에서 연장이 멈추는 이유와, 다음 사이클을 위해 linker를 절단하는 이유를 포함하시오.

### 문제 23. 가역적 종결기의 도입과 제거

DNA Script의 **3′-ONH₂** 방식과 Molecular Assemblies의 FES에서 사용하는 **3′-인산** 방식을 비교하시오. 각각의 단일 잔기 도입, 추가 연장 억제, 차단기 제거 방법을 설명하고, 두 방식 모두 개조 TdT가 필요한 이유를 설명하시오. 답은 표로 작성하시오.

### 문제 24. PCA에 의한 유전자 조립

PCA(Polymerase construction and amplification, 중합효소를 이용한 구축과 증폭)로 짧은 올리고에서 긴 이중가닥 DNA를 만드는 과정을 설명하시오. **올리고 간 중첩 영역, 어닐링과 신장, 양 끝 증폭 프라이머**의 역할을 포함하시오. 구축 단계의 중합효소 반응과 TdT 합성의 주형 사용 차이도 설명하시오.

### 문제 25. 치환 오류와 MutS를 이용한 제거

길이가 동일하고 한 염기만 다른 두 올리고를 일반적인 길이 기반 정제로 구분하기 어려운 이유를 설명하시오. MutS를 이용한 오류 제거에서 **변성, 재혼성화, 불일치 염기쌍 형성, MutS 결합과 분리**가 필요한 이유를 순서대로 설명하시오.

## 7-2강 — XNA의 구조·합성·분석과 데이터 저장

### 문제 26. XNA의 정의와 구조 변형

XNA(Xeno nucleic acid, 이종 핵산)의 정의를 쓰고, 천연 DNA와 비교하여 **당 또는 골격의 변형**을 설명하시오. LNA(Locked nucleic acid, 잠금 핵산), TNA(Threose nucleic acid, 트레오스 핵산), PNA(Peptide nucleic acid, 펩타이드 핵산)의 대표적인 구조 차이를 각각 쓰시오.

### 문제 27. LNA의 구조 고정과 결합 안정성

LNA에서 당 고리의 어느 위치가 연결되어 구조가 고정되는지 표시하고, 이 구조 고정이 상보적 가닥과의 결합 안정성에 영향을 주는 이유를 설명하시오. **Tm(융해 온도)**이 높다는 것과 **뉴클레아제에 잘 분해되지 않는다는 것**이 서로 다른 성질인 이유도 설명하시오.

### 문제 28. XNA의 화학 합성과 효소 합성

XNA의 화학 합성과 효소 합성의 기본 원리와 제한 요인을 비교하시오. **단량체 제조의 복잡성, 반복 반응의 누적 수율, 중합효소의 변형 기질 수용성, 주형 의존·비의존 합성의 차이**를 포함하시오.

### 문제 29. XNA 분석 장치의 측정 원리

UV–Vis thermal melting(자외선–가시광 열용융 분석), CD(Circular dichroism, 원편광 이색성), MS(Mass spectrometry, 질량분석법)가 각각 무엇을 측정하고 어떤 정보를 제공하는지 설명하시오. 이중가닥의 가역적 2상태 전이를 가정하여 **온도에 따른 260 nm 흡광 곡선**을 그린 뒤, Tm과 흡광 증가의 원인을 표시하시오.

### 문제 30. XNA 데이터 저장의 밀도·내구성·판독

서로 구분 가능한 염기를 동일한 확률로 사용하는 이상적인 경우, 4종 및 8종 알파벳의 뉴클레오타이드당 정보량을 각각 계산하시오. 또한 TNA의 뉴클레아제 저항성이 데이터 보존에 도움이 되는 이유와, XNA를 표준 PCR·NGS로 판독할 때 효소 호환성을 확인해야 하는 이유를 설명하시오. **DNA로의 전환 후 판독**과 **직접 nanopore(나노포어) 판독**의 차이를 포함하시오.
