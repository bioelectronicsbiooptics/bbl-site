cis와 trans의 전기적 정의

  • Cis: 시료를 넣는 쪽으로 정의
  • Trans: 막의 반대쪽
  • 이 강의의 전압: Vm=Vtrans−Vcis
  • 두 용액 사이 전위차와 전극 기준점

Vₘ = Vtrans − Vcis

DNA 이동과 이온 전류 방향

  • 예: cis=0 mV, trans=+180 mV
  • 음전하 DNA의 전기영동 힘: trans 쪽
  • 양전하의 관습적 전류 방향: trans에서 cis
  • 실제 분자 운동은 전기삼투·motor에도 영향

같은 전위차의 두 표현

VcisVtransVₘ
0 mV+180 mV+180 mV
−180 mV0 mV+180 mV
0 mV−180 mV−180 mV

  • 두 경우 Vtrans−Vcis=+180 mV

16-bit 양자화 계산

  • 16-bit: 2^16=65,536개 코드
  • 가상 입력 범위 −10~+10 V
  • 전압 LSB≈20 V/65,536=0.305 mV
  • 1 mV/pA 변환 이득이면 약 0.305 pA/code

ΔVADC ≈ Vspan / 2^b ; ΔI ≈ ΔVADC / Gain

Sampling rate와 시간 간격

  • fs=50 kHz이면 Δt=20 μs
  • 1 ms 사건에는 약 50개 샘플
  • 50 μs 사건에는 약 2.5개 샘플
  • 사건 모양과 진폭 추정의 표본 수

Δt = 1/fs ; 사건당 샘플 수 ≈ fs × τ
