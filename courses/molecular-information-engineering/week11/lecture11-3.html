Zero-Mode Waveguide의 광학

zero-mode의 뜻

원통형 금속 도파관은 차단 파장 λc ≈ 1.7 d 보다 긴 빛을 전파시키지 못함 (TE11 모드) → 도파관 안 전파 모드가 0개

계산

d = 70 nm → λc ≈ 1.7 × 70 ≈ 119 nm
가시광 400–700 nm ≫ 119 nm → 빛은 들어가지 못하고 입구에서 지수적으로 사라지는 소산파만 남음

결과

바닥 20–30 nm만 밝음 → 관찰 부피 zL(10⁻²¹ L) 수준 · 위쪽 µM 용액은 어둠 속

표면화학

Al 벽은 PVPA로 막고 유리 바닥에만 중합효소 고정 → 구멍당 효소 1개 비율 ≈ 30% (Poisson 한계 e⁻¹ ≈ 37%)

https://doi.org/10.1126/science.1079700

관찰 부피와 평균 분자 수

정의 Definition
  • 관찰 부피 V = 빛이 충분히 들어와 형광을 내게 하는 공간
  • ZMW 밝은 부분을 원기둥으로 근사: V ≈ π (d/2)² · Λ (d 지름, Λ 소산파 감쇠 길이)
  • 부피 속 평균 분자 수: N = C · V · NA (C 몰농도, NA = 6.0×10²³)
  • 단위: 1 fL = 10⁻¹⁵ L · 1 aL = 10⁻¹⁸ L · 1 zL = 10⁻²¹ L
  • N ≲ 1 이면 형광 펄스 하나 = 분자 하나
예제 Example
  • d = 70 nm, Λ = 20 nm
    V = π × (35×10⁻⁹ m)² × 20×10⁻⁹ m
    = 7.7×10⁻²³ m³ = 7.7×10⁻²⁰ L ≈ 77 zL
  • 10 µM: N = 10⁻⁵ × 7.7×10⁻²⁰ × 6.0×10²³ ≈ 0.46개
  • 1 µM: N ≈ 0.05개
  • 공초점 0.5 fL과 비교: 0.5×10⁻¹⁵ ÷ 7.7×10⁻²⁰ ≈ 6,500배 작음
  • ZMW.pptx 14번: 100 nm ZMW · 0.1–10 µM에서 부피 안 분자 0.01–1개

교육용 관찰 부피 근사 / https://doi.org/10.1126/science.1079700

반복 판독과 consensus의 모형

정의 Definition
  • 한 바퀴에서 한 자리의 오류 확률 p, 바퀴끼리 독립이라 가정
  • n바퀴(홀수) 다수결이 틀릴 확률:
    Perr(n) = Σk>n/2 C(n,k) pk (1−p)n−k
  • 품질 점수 Q = −10 log₁₀ P · Q20 = 99% · Q30 = 99.9% · Q40 = 99.99%
  • 한계: 같은 자리에서 반복되는 계통 오류(호모폴리머)는 독립 가정이 깨짐 → 다수결로 안 사라짐
예제 Example · p = 0.10
  • n = 3: 3p²(1−p) + p³ = 0.027 + 0.001 = 0.028 → Q15.5
  • n = 5: 10p³(1−p)² + 5p⁴(1−p) + p⁵ ≈ 0.0086 → Q20.7
  • n = 7 → 0.0027 (Q25.6) · n = 9 → 0.00089 (Q30.5) · n = 11 → Q35.3
  • p = 0.15이면 n = 9 → Q22.5 · n = 15 → Q32
  • 실측 비교: Wenger 2019 “10 passes to achieve Q30” ↔ 모델 n ≈ 9

독립 오류의 다수결 모형 / https://doi.org/10.1038/s41587-019-0217-9
